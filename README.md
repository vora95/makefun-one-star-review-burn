The review is **"One star. Sleep promised eight hours of rest and delivered a 3 a.m. staring contest with the ceiling."** — a deadpan complaint filed in earnest against sleep: the sharpest true grievance (the 3 a.m. wake-up everyone recognises), held straight until the sting lands in the last few words.

`main.py` writes the single line to `/output/entry.txt` and verifies it by reading it back byte-for-byte.
